# xc-union-sdk-wechat

微信 SDK 聚合模块，包含微信公众号相关的 SDK 实现。

## 模块列表

| 模块 | 说明 | 包名 |
|------|------|------|
| xc-union-sdk-wechat-mp | 微信公众号 SDK | com.xc.union.sdk.wechat.mp |

## 快速开始

```xml
<!-- 引入微信 SDK -->
<dependency>
    <groupId>com.xc.union</groupId>
    <artifactId>xc-union-sdk-wechat-mp</artifactId>
</dependency>
```
