# xc-union-sdk-rebate

返利平台 SDK 聚合模块，包含各大返利平台的 SDK 实现。

## 模块列表

| 模块 | 说明 | 包名 |
|------|------|------|
| xc-union-sdk-rebate-dtk | 大淘客 SDK | com.xc.union.sdk.rebate.dtk |
| xc-union-sdk-rebate-hdk | 好单库 SDK | com.xc.union.sdk.rebate.hdk |
| xc-union-sdk-rebate-jd | 京东 SDK | com.xc.union.sdk.rebate.jd |
| xc-union-sdk-rebate-pdd | 拼多多 SDK | com.xc.union.sdk.rebate.pdd |
| xc-union-sdk-rebate-tbk | 淘宝客 SDK | com.xc.union.sdk.rebate.tbk |

## 快速开始

```xml
<!-- 引入所有返利 SDK -->
<dependency>
    <groupId>com.xc.union</groupId>
    <artifactId>xc-union-sdk-rebate</artifactId>
</dependency>
```
