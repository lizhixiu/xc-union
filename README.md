# lite-union

`lite-union` is rebuilt as a multi-project repository based on `lite-api-core`.

## Backend Modules (Maven)

- `lite-union`
  - `lite-union-client-service`
  - `lite-union-admin-service`
  - `lite-union-job-service`

## Frontend Modules (Non-Java)

- `lite-union-admin-ui`
- `lite-union-client-ui`

## Build Backend

```bash
mvn clean compile
```
